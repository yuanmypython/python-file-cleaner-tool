# 电脑文件清理工具
## 项目简介
基于Python开发的磁盘文件清理工具，解决电脑文件杂乱、重复文件占用空间、空文件冗余的问题，支持识别并清理空文件、重复文件，同时保留原始备份，避免误删风险。

## 技术栈
- Python 3.x
- 核心库：os, shutil, pathlib, hashlib

## 核心功能
- ✅ 一键识别并清理空文件、无效0KB文件
- ✅ 基于文件哈希值识别重复文件，自动保留原始备份
- ✅ 支持自定义清理规则，可指定清理文件类型
- ✅ 适配Windows系统，清理过程可预览，安全可控

## 使用方法
1.  下载`file_cleaner.py`脚本
2.  确保已安装Python环境
3.  运行脚本，选择需要清理的文件夹路径
4.  选择清理规则（空文件/重复文件），预览待清理文件
5.  确认后执行清理，自动生成清理日志
